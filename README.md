# 一副牌升级游戏模拟器

基于 Python 的**单副牌升级（打百分/打拖拉机）**桌面模拟器，完整实现从发牌到结算的全部流程。

提供三种运行模式：**GUI 可视化**、**CLI 可视化**、**批量模拟（Excel 导出）**。

📖 **详细规则说明**：[钉钉文档 - 一副牌升级规则](https://alidocs.dingtalk.com/i/nodes/DnRL6jAJMGR5xdnYuXyqN0DYWyMoPYe1?utm_scene=person_space)

## 快速开始

### 环境要求

- Python 3.8+
- Tkinter（Python 自带）
- 可选：`openpyxl`（Excel 导出）

```bash
pip install openpyxl
```

### 运行方式

```bash
# GUI 可视化模拟器（推荐）
python gui.py

# CLI 可视化模拟器
python cli_visual.py

# 批量模拟 + Excel 导出
python game.py --rounds 10 --seed 42
```

| 按钮 | 功能 |
|------|------|
| ▶ 开始 | 初始化新游戏，随机发牌 |

### 设置项

| 设置 | 说明 |
|------|------|
| 延迟 | 自动播放速度：慢速(800ms) / 中速(400ms) / 快速(150ms) / 极速(30ms) |
| 牌型 (轰) | 发牌要求：双方至少各有玩家拥有指定数量的轰，如 `1` 或 `1:2` |
| 种子 | 固定随机种子（留空为随机），相同种子可复现相同牌局 |
| 轮数 | 游戏总轮数（留空则无限进行，直到一方过7获胜） |

## 🎬 CLI 可视化模拟器

交互式终端动画版本，每手牌都能看到：

```bash
python cli_visual.py                    # 逐步模式（按回车推进）
python cli_visual.py --fast              # 快速模式（自动播放）
python cli_visual.py --seed 42           # 固定随机种子（可复现）
python cli_visual.py --seed 42 --fast    # 固定种子 + 快速模式
python cli_visual.py --seed 42 --hong 1  # 要求双方至少各有1个轰
python cli_visual.py --seed 42 --hong 1 --510k 1  # 同时要求轰和510K
python cli_visual.py --seed 42 --hong 1:2  # 要求双方至少各有1~2个轰
python cli_visual.py --seed 42 --hong 1 --zha 1 --510k 1  # 三种牌型都有
python cli_visual.py --rounds 10 --seed 42  # 跑10轮并输出Excel
python cli_visual.py --single            # 只看一局
```

### 牌型控制参数

发牌时可通过参数要求双方至少各有1位玩家拥有指定牌型：

| 参数 | 格式 | 说明 |
|------|------|------|
| `--hong N[:M]` | `1` 或 `1:2` | 双方至少各有玩家拥有 N~M 个轰 |
| `--zha N[:M]` | `0:1` | 双方至少各有玩家拥有 N~M 个炸 |
| `--510k N[:M]` | `1` | 双方至少各有玩家拥有 N~M 个510K |

`game.py` 同样支持这些参数：
```bash
python game.py --rounds 10 --seed 42 --hong 1 --510k 1
```

## 游戏简介

升级是中国流行的扑克牌游戏，4 人分两队对抗。本模拟器实现**一副牌（含大小王共 54 张）**的完整规则：

- **4 名玩家**：玩家 1~4，对家为队友（玩家 1&3 vs 玩家 2&4）
- **庄家方 vs 抓分方**：每局轮流坐庄
- **级牌从 7 开始**，先打过 7 的一方获胜
- **3 个 AI 机器人**自动出牌，模拟真实对抗

## 核心规则

### 牌力大小

| 类别 | 内容 | 牌力等级 |
|------|------|----------|
| 常主 | 大王、小王 | 最高 |
| 级牌 | 当前级数的所有花色 | 次于大小王 |
| 红桃 3 | 固定主牌（参） | 特殊主牌 |
| 2 | 固定主牌 | 低于红桃 3 |
| 主牌 | 与定主花色相同的牌 | 高于副牌 |
| 副牌 | 其余牌 | 最低 |

### 游戏流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  发牌    │───▶│  定主    │───▶│  埋底    │───▶│  捡主    │
│ 54→48+6  │    │亮/闷/底  │    │庄家选牌  │    │(有闷牌时)│
└─────────┘    └─────────┘    └─────────┘    └─────────┘
                                                        │
┌─────────┐    ┌─────────┐                             ▼
│  过7检查  │◀───│  结算    │◀─── 12 圈出牌 ◀────────────┘
│ 是否结束  │    │ 算分升级 │     (每圈 4 张)
└─────────┘    └─────────┘
```

### 定主方式

1. **未定庄闷牌**（概率 ~25%）— 发牌阶段，任一玩家可暗扣一张级牌
2. **亮牌**（概率 ~50%）— 定庄后，庄家方手持级牌亮出，决定主花色
3. **闲家闷牌**（概率 ~50%）— 定庄后，闲家暗扣一张级牌（与亮牌互斥）
4. **底牌首张**（兜底）— 以上均未触发时，翻底牌第一张定主

### 埋底 & 捡主

- **埋底**：庄家从手牌中选 0~6 张放入底牌（保持 6 张），底牌中分牌（5/10/K）尽量不超过 35 分
- **捡主**：如果存在闷牌，翻开闷牌确定主花色后，抓分方从底牌中拣出所有主牌，并弃回同等数量的牌

### 出牌规则

- 每局共 **12 圈**，每圈每人出牌数量由首出者决定（单张 / 3张510K / 4张轰）
- **首出**：优先轰 > 510K > 安全单张（非分非主小牌）
- **跟牌**：必须跟首出花色且出相同数量；无该花色可用主牌毙或垫副牌；手牌不足时全部打出
- **抓分目标**：5、10、K 为分牌，分别计 5、10、10 分

### 结算规则

| 抓分方得分 | 扣底 | 结果 | 庄方升级 | 抓方升级 |
|-----------|------|------|---------|---------|
| 0 分 | 否 | 光头 | +3 | 0 |
| 5~35 分 | 否 | 干受苦 | +1 | 0 |
| 40~45 分 | 否 | 上台 | 0 | +1 |
| ≥50 分 | 否 | 升级 | 0 | (分-40)/10+1 |
| <40 分 | 是 | 干扣底 | 0 | 0 |
| ≥40 分 | 是 | 扣底升级 | 0 | 基础+3~4 |

**扣底加成**：最后一圈抓方赢则扣底。若最后一圈最大牌是**大王**，额外 +4 级；否则 +3 级。

### 过 7 规则（胜利条件）

1. **庄家方级牌 > 7** → 庄家方直接获胜 🏆
2. **抓分方级牌 > 7** → 强制停在 7，获得庄权，需**守庄一局**：
   - 守庄成功（对方得分 ≤ 35）→ 抓分方获胜 🏆
   - 守庄失败 → 对方上台，继续比赛

## Excel 报告说明

生成文件包含 4 个 Sheet：

### Sheet 1: 游戏总览

| 列 | 内容 |
|----|------|
| 轮次 ~ 结果 | 轮次 + 每局关键数据一行 |
| 定主方式 | 亮牌 / 闷牌 / 底牌首张 |
| 抓分 | 抓分方本局得分 |
| 扣底 | 最后一圈是否被对方抓走 |
| 升级 | 庄方/抓方各升几级 |

### Sheet 2: 轮次统计

- 每轮的局数范围、胜方汇总
- 合计行显示总局数和最终胜方

### Sheet 3: 每局详情

- 初始手牌（12 张/人）
- 底牌变化（埋入 → 取回 → 拣出 → 弃回）
- 12 圈完整出牌记录
- 操作日志（亮牌/闷牌/捡主/结算全过程）

### Sheet 4: 出牌记录总表

- 所有局的出牌按圈汇总，方便统计分析

## 技术实现

- **Card / Deck**：扑克牌数据结构与一副牌创建
- **Bot**：AI 出牌策略（首出优先轰/510K、跟牌判断是否抢分、庄家积极毙牌、抓方保守用主）
- **Game**：游戏引擎，串联发牌→定主→埋底→出牌→结算→过7检查的完整循环
- **RoundRecord**：单局数据记录，用于 Excel 导出
- **GameGUI**：Tkinter Canvas 图形界面（圆角牌面渲染、逐玩家揭示动画、步进/自动双模式）
- **save_excel**：使用 openpyxl 生成带格式的多 Sheet Excel 报告
